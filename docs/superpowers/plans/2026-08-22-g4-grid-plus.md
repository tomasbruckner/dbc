# G4 Grid+ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Local sort, per-column filters, Ctrl+F in-result search, cell detail popup, export CSV/TSV/JSON/INSERT, column visibility menu, FK joined columns (preview LEFT JOIN rewrite + ad-hoc batched lookup), per-table view memory.

**Architecture:** The grid gains a *row-view layer*: a `RowView` (permutation + filter index `Vec<u32>`) between the ResultBuffer and rendering — sort/filter/search all operate on it, never mutating the buffer. Exports stream through the same cell access. FK joins: preview tabs re-run a rewritten LEFT JOIN SQL; ad-hoc tabs batch-fetch referenced rows through the existing runner. View prefs persist in dbc-state keyed by (connection, schema, table).

**Tech Stack:** Rust, GPUI (pinned 907ed09), Arrow, serde/toml.

**Spec:** docs/superpowers/specs/2026-08-22-gui-target-design.md §1 (Grid ~lines 86-99: view memory, FK columns choice "B"), §2 row G4.

## Global Constraints

- dbc-core never sees GPUI; dbc-ui never imports driver crates outside connect.rs; persistence in dbc-state.
- Errors are values; export/sort/filter failures surface in status, never panic; spill-read fallback cells ("<spill read error>") must not break sort/filter/export.
- Sort/filter run on the UI thread — they must be O(n) scans + sort, with a status "řadím…" for large sets; no per-frame recompute (cache the RowView, invalidate on buffer growth/settings change; the grouped_cache/history_cache precedent is binding).
- Exports never include secrets; file writes are atomic-ish (write temp, rename) and report the written path in status.
- Czech labels (Filtr…, Export, Sloupce, Detail buňky, Hledat v výsledku…); `error:` prefix convention.
- Build/test only with explicit `-p`; suites stay green (dbc-ui 77, dbc-state 17, dbc-core 13, dbc-buffer 5, dbc-driver-sqlite 9).
- Version bump to 0.4.0 at merge, not in a task.

```rust
// row_view.rs — GPUI-free where possible; cell access via a closure so tests
// don't need a real ResultBuffer.
pub struct RowView {
    /// Visible rows of the underlying buffer, in display order.
    /// Identity mapping when no sort/filter active (cheap, not materialized:
    /// use an enum { Identity(usize), Mapped(Vec<u32>) }).
    order: RowOrder,
    pub sort: Option<(usize, bool)>,          // (source col ix, ascending)
    pub filters: Vec<(usize, String)>,        // (source col ix, needle) — Task 3
}
impl RowView {
    pub fn identity(rows: usize) -> Self;
    pub fn len(&self) -> usize;
    pub fn source_row(&self, display_ix: usize) -> usize;
    /// Rebuilds order from scratch: applies filters (Task 3; empty now) then
    /// sort. `cell(row, col) -> String` is the accessor; `rows` the source
    /// count. Sort compare: try parse both as f64 → numeric; else
    /// case-insensitive string. Stable.
    pub fn rebuild(&mut self, rows: usize, cell: &mut dyn FnMut(usize, usize) -> String);
}
```

- grid.rs: `ResultGrid` gains `view: RowView`, `hidden_cols: Vec<bool>` (by source col ix), and renders through them: uniform_list count = view.len(); row ix → view.source_row; visible columns = those not hidden (header + cells + widths all skip hidden). Header click (outside the resize handle) cycles sort: none → asc → desc → none, then `rebuild` + notify; sort indicator ▲/▼ in header.
- Rebuild triggers: header sort click; buffer growth (streaming) — on Batch, if a sort/filter is active, DON'T resort per batch: mark dirty and resort once on Finished (status note "seřazeno po dokončení"); identity view appends are free.
- Copy/selection operate on DISPLAY indices mapped through source_row (fix on_copy).
- Public helper for Task 6: `set_view_state(sort, hidden_col_names)`, `view_state()` for persistence.

```rust
// export.rs — pure serialization, writer-agnostic; tests feed a Vec sink.
pub enum ExportFormat { Csv, Tsv, Json, Insert }
/// Streams the CURRENT VIEW (sort/filter applied, hidden columns excluded)
/// row by row into `w`. `headers` = visible column names; `table_name` used
/// for Insert. CSV: RFC4180 quoting (quote when needed, "" escape, CRLF).
/// TSV: tabs/newlines in cells replaced by spaces (documented). JSON: array
/// of objects, string values (typed later), streaming writer (no full
/// materialization). Insert: `INSERT INTO {quoted table} ({cols}) VALUES
/// (...);` per row, single-quote escaping, NULL for empty-marker cells —
/// cell text "NULL" is ambiguous; document: we export the display text,
/// quoted, except cells whose source Arrow value is null → need a
/// null-aware accessor: `cell(row, col) -> Option<String>` (None = SQL NULL).
pub fn export<W: std::io::Write>(w: &mut W, format: ExportFormat, headers: &[String],
    table_name: &str, rows: usize, cell: &mut dyn FnMut(usize, usize) -> Option<String>)
    -> Result<(), String>;
```

- Null-awareness: dbc-buffer gains `pub fn cell_is_null(&mut self, row, col) -> bool` (Arrow Array::is_null through the same slot lookup; spill-read failure → treated as non-null with the error text). Small dbc-buffer addition + test.
- UI: toolbar "Export ▾" → dropdown (CSV / TSV / JSON / INSERT). Target path via GPUI save dialog if the pin exposes one (check `cx.prompt_for_new_path` in the vendored source; if unavailable/unreliable on Windows, fall back to writing `dbc-export-{timestamp}.{ext}` into the user's Downloads (dirs::download_dir) and say so in status). Write via std::io::BufWriter to temp file + rename; status "exportováno: {path} ({n} řádků)". Export runs synchronously for ≤50k rows; larger → status "exportuji…" and run on a std::thread with a completion notify (no tokio needed — use the existing cx.spawn/background pattern if simpler; document choice).
- Column visibility: toolbar "Sloupce ▾" → checklist dropdown of all source columns (checkbox toggles hidden_cols, rebuild widths mapping; at least one column must stay visible).
- Tests (pure, Vec sink): CSV quoting (comma, quote, newline cases), TSV replacement, JSON escaping + null → null, INSERT escaping + NULL + quoted table/idents (reuse dbc_core::ddl::quote_ident), row order follows the view.
